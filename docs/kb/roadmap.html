Later, through the lens

  • Crew on the watch. "MARCUS is lifting" on the watch home; it already mirrors the phone's presence.
  • Friends' loadouts. Carry an equipped badge in a Game Center score context so crew pills can wear them.
  • Season themes that change a rule. S01 is "the game"; a season should ship at least one temporary mechanic, not just a ladder.
  • Gym-hosted events and brand rewards. Plug into LiveEventProviding with the same shape: title, window, XP, participant count.
  • Per-lift leaderboards. Depend on parse reliability.
  • Let players create events. The end state of the philosophy: we create the system in which things happen.
  • Notifications. None until there is a ritual worth one; opt-in; one per ritual at most.

Known debt

  • ~2,400 lines of unreachable code: ChatView, ChatBlockView, InsightsTab, InsightStoryView, StoryCarouselView, HomeIntelligenceEngine, InsightsIntelligenceEngine, StoryReadTracker. ChatEngine and ConversationStore are constructed with no consumer. The insights engine no longer runs; it was spending the bundled OpenAI key on stories nothing rendered.
  • InsightsStore.ingestedWorkoutIDs is in memory only; the persisted PR ledger on PlayerProgress keeps XP correct.
  • ProgressionService.rebuild(from:) credits all historical XP to the current season.
  • Profile's PR tile is max(prCount, lifts tracked); two different live-session counts exist (Profile vs the live_sessions board).
  • The event clock override is a frozen instant, so countdowns do not tick under it, and event XP is not paid under it because workouts are stamped with the real time.
  • Watch: the HealthKit permission sheet cannot be completed in the simulator; test on hardware.

Cut on purpose

Daily login rewards. Streak-loss anxiety. Push notifications for now. Inflated presence. Loot and random rewards. Paid XP or tiers. A permanent rank line on Home. Double XP every weekend. Countdowns on non-events. Chat in rooms. Arbitrary badges. Seasons as renamed releases. The point is not to make everything Fortnite. The point is to learn how Fortnite makes a digital product feel alive.
